One funny fortune-cookie line for a crypto trader who just got liquidated, written to `/output/entry.txt` by a small deterministic Node 22 program (stdlib only, no network, no randomness). Entry for the [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) bounty on make.fun.

Run it with `node main.ts` (Node 22.18+), or `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` to write the entry elsewhere for local testing.
